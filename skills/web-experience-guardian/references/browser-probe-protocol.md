# 按请求运行浏览器探针

仅在用户明确要求实测时使用。确认目标应用、入口 URL、可用浏览器和本次要观察的交互。沿用项目现有工具和夹具，在请求范围内记录所选浏览器、视口、路由、状态、证据位置。用能解释问题的最小场景；无需为无关规则运行探针。

| 目的 | 探针和可报告的证据 |
| --- | --- |
| W-A1 / W-A3 几何 | 在产品支持的受影响宽度比对同一容器的内容边、黏性栏和可滚动边界。记录视口、选择器、元素边坐标与溢出像素。区分有意缩进、浏览器取整和独立滚动容器。 |
| W-B1 / W-B2 稳定性 | 在相同滚动位置、视口和数据夹具下观察等待与完成分支，记录同一锚点的位移（px）并按需保存截图。报告真正的 CLS 时另外采集浏览器 Layout Instability 性能条目并按 CLS 规则计算。缺少该能力时只报告观测到的位移。 |
| W-C1 / W-C2 / W-C3 状态 | 按改动选择会话初始化、刷新/后退或列表详情联动。需要变更数据时使用可恢复的本地测试记录或已有隔离夹具；没有可用夹具就记录该路径未验证。 |
| W-B3 / W-D1 / W-D2 / W-D3 反馈 | 沿触发步骤记录未处理异常或失败响应及其用户结果。检查失败能否恢复、键盘焦点走向、弹层关闭和连续点击产生的副作用。 |

网络延迟如由测试拦截器注入，限定到目标请求，并在退出或超时路径清理本次拦截及监听。报告证据的实际范围。只跑 Chromium 时保留 Safari 等相关覆盖缺口；未执行第三方登录、真实弱网或移动端键盘时，按受影响行为在共享契约中标明。只声明本次实际生成的截图路径。
