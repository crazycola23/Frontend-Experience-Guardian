# Evals

These scenarios test whether Frontend Experience Guardian changes agent behavior in measurable product-quality ways.

Run each task twice when possible:

1. baseline agent without the Skill;
2. same agent/model/tooling with the Skill.

Do not score based on visual taste alone.

## Suggested scoring (0–2 each)

- **Correctness:** requested functionality remains correct.
- **Restraint:** no unnecessary copy/cards/badges/fake production data.
- **Stability:** geometry remains stable across relevant states.
- **Scroll quality:** no unjustified nested/internal/page-horizontal scrolling.
- **Responsive:** layouts reflow without conflicting breakpoint behavior.
- **Efficiency:** common task paths avoid unnecessary interaction cost.
- **Accessibility:** no obvious focus/keyboard/contrast/touch regression.
- **Scope discipline:** agent avoids unrelated product expansion.
- **Finalization:** names/comments/delivery describe accepted final state.

Maximum: 18 points per scenario.

Record not only the score but also concrete regressions introduced or prevented.
